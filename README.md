# NPH / YABA member portal (demonstration)

React + TypeScript prototype for stakeholder walkthroughs. Sample data only. Checkout is simulated.

## Run locally

```bash
cd demo
npm install
npm run dev
```

Open http://localhost:3000 — choose a persona, then use the header to switch roles.
